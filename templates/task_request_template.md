# 司令AI向けタスク投入テンプレート

以下の枠組みをコピーし、Antigravity のメインチャット（司令AI）に送信してください。

---

```text
このWorkspaceの次のファイルを実際に読み込んでください。

- prompts/00_common.md
- prompts/10_commander.md

あなたは司令AIとして動作してください。

1. `redmine-ops` スキルを使用して、Redmineの親プロジェクト `Antigravity` (`antigravity`) 配下に本プロジェクトをサブプロジェクトとして登録（既にあれば確認）してください。
2. サブエージェントの起動時には、対応する役割プロンプト（prompts/20_researcher.md, prompts/30_executor.md, prompts/40_evaluator.md）と共通プロンプトを初期指示として渡し、Antigravity のサブエージェント起動機能を使ってください。
3. 計画（P1）は対象サブプロジェクトの Redmine Wiki に記述し、分解したすべてのタスクを Redmine Issue として登録した上で、対象成果物の変更前に必ず計画（P1）を提示して私の承認を待ってください。
4. 各タスクはサブエージェントに処理させ、進捗・結果・評価判定を Redmine Issue に連動させてください。

【対象プロジェクト名 / Redmineサブプロジェクト識別子】
（例：MultiAgentBase / multiagent-base）

【目的】
（例：既存の認証モジュールにJWTリフレッシュトークン機能を追加し、セキュリティと利便性を向上させる）

【対象】
（例：src/auth/ 配下のコード、tests/auth/ 配下のテストコード、README.md）

【制約】
（例：
- 既存のDBマイグレーションファイルは編集しない
- 外部APIへの通信はモックを使用する
- 本番設定ファイル（.env）は参照しない
- 変更成果物のコミット/pushは行わない）

【完了条件】
（例：
1. リフレッシュトークンの発行・更新処理が実装されていること
2. ユニットテストおよび結合テストがすべてPassすること
3. 評価AIによる独立レビューで指摘（重大バグ・脆弱性）が解消されていること
4. Redmine の Wiki（計画）および全 Issue（タスク）が完了状態に更新されていること）
```
